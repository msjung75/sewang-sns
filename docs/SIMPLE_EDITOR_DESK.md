# 대표 검토 화면

첫 화면은 이번 호 내용과 지금 필요한 결정 하나를 보여준다. 흐름은 내용 고르기 → 조사·구성 → 원고 검토 → 최종 승인이다. 기사 수와 AI 제안 수를 구분하며, 현재 선택 기사 묶음에 포함되지 않은 과거 요청은 알림·설정에서 조회한다.

결과가 준비되면 ‘결과 읽고 결정하기’로 실제 결과와 한계를 확인한다. 근거가 부족하면 ‘근거를 보완해 다시 조사하기’를 선택한다. ‘논리가 부족하거나 주제를 바꾸고 싶어요’에서 대체 후보 조사를 요청하거나 이번 호에서 제외해 보관할 수 있다. 대체 후보 요청만으로 기존 주제를 해제하지 않는다. 새 후보 최종 선택은 대표가 한다.

접수·실제 시작·검토 대기를 구분한다. 완료되지 않은 작업을 완료로 표시하거나 근거 부족 결과를 일반 진행 버튼으로 넘기지 않는다. 알림 수집과 휴대폰 설정은 알림·설정에 보관한다. 원고 승인, 번역, 발송 권한과 기존 데이터는 변경하지 않는다.

검증: 현재 작업 상태 판정 및 이전 계획 제외 단위 테스트, 메모리 API에서 결과 열기·대체 주제 요청·보완 조사 클릭, 390px 화면에서 가로 넘침 없음.
