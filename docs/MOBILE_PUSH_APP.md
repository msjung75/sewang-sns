# 휴대폰 설치형 관리센터와 서버 푸시

기존 /ai-center를 아이폰 Safari 홈 화면 또는 안드로이드 Chrome에 설치합니다. 앱스토어 배포·새 유료 플랜·신규 외부 계정은 사용하지 않습니다. 홈 화면 설치 후 대표 로그인, 휴대폰 알림 켜기, 테스트 요청 순서입니다. 아이폰은 홈 화면 앱에서 등록해야 합니다.

서비스 워커는 푸시 수신과 알림 클릭만 처리하며 보호된 페이지·API·로그인 상태를 캐시하지 않습니다. 오프라인 화면은 서버 상태를 추측하지 않습니다. 알림에는 일반 상태만 포함하고 원고/기사/대표 의견을 넣지 않습니다. 클릭 대상은 같은 origin의 AI 관리센터로 제한합니다.

구독은 기존 고정 private staging API에 저장합니다. owner 인증은 구독·해제·테스트만 허용하며 전체 구독/서명키 구성/수신 증빙 API는 admin 전용입니다. 외부 푸시 endpoint는 HTTPS의 Apple/Google/Mozilla 제공사만 허용합니다. 비밀번호 변경 시 auth_version이 달라진 기기는 발송 대상에서 제외하며 다시 등록해야 합니다. 개인 서명키는 Mac private mobile-push/vapid.json 0600에만 저장합니다. Git·브라우저·로그로 보내지 않습니다.

기존 5분 Mac 동기화가 조사 running/awaiting_review/blocked 및 번역 상태 변경을 비교해 암호화 Web Push를 보냅니다. 초기 등록은 과거 상태를 baseline으로 기록하고 연결 안내를 한 번 보냅니다. 기기별 ledger/고정 event tag로 중복을 줄이고 실패는3회까지 재시도합니다. 제공사404/410은 등록을 정리합니다. 제공사의 접수와 실제 휴대폰 도착을 구분하며 후자는 사용자 확인이 필요합니다. Mac 중단·네트워크 단절 동안 전송되지 않습니다. 휴대폰 절전·집중 모드와 제공사 지연으로 늦어질 수 있습니다. 새 일정은 추가하지 않습니다.

검증: 프런트엔드27개, backend56개, Python 이벤트 개인정보 필터1개, 실제 Web Push 암호화·복호화/VAPID1개 테스트. 실제 기기 수신은 설치·허용 후 최종 확인해야 합니다.
