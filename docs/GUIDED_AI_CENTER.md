# 세왕 AI 관리센터

전용 진입점은 `/ai-center`입니다. SNS 메뉴에서 AI 항목을 제거하고 `/ops`는 새 진입점으로 이동합니다. 로그인·기존 원고·후보함·선택과 발행 이력은 유지합니다.

대시보드는 후보함과 실제 제출 요청을 구분하고 대표 확인 대기 결과 및 주제별 진행을 표시합니다. 자료 선택 → 명시적 조사 시작 → 주제별 결과 확인 → 구성·분석 확인 → 원고 반영 결정으로 이어집니다. 같은 후보함 버전은 기존 작업실을 열며, 변경된 선택은 새 요청입니다. 접수·작업 시작·대표 확인·승인 상태를 구분합니다. 자동으로 대표 승인을 대신하지 않습니다.

키워드 화면은 수집 자료의 주제 관찰과 실제 문서 수 시계열을 구분합니다. 검색량으로 표시하지 않으며, 동일 조건의 완결된 14일 자료가 없으면 증감을 보류합니다. 이미 수집된 데이터의 동기화만 사용합니다. 기존 유료 사용 한도와 스케줄을 늘리지 않습니다.

선택 기사 수만으로 완성도를 주장하지 않습니다. 분석 단계에서 시장 통계·키워드·국내외 사례·거래처 실행 항목·기존 발행물 차별점의 확보 및 부족 상태를 확인합니다. 실제 카카오 발송·결제·운영 리포트 게시에는 별도 최종 검토가 필요합니다.

검증: 프런트엔드 23개 테스트, 백엔드 52개 테스트, TypeScript 및 production build. 실제 스냅샷을 복사한 메모리 API로 2건 조사 요청·작업실 이동·재열기(중복 방지)를 확인했습니다. 실제 사용자 후보함은 이 테스트로 바꾸지 않았습니다.
