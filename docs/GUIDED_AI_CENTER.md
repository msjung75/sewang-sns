# 세왕 AI 관리센터

전용 진입점은 `/ai-center`입니다. SNS 메뉴에서 AI 항목을 제거하고 `/ops`는 새 진입점으로 이동합니다. 로그인·기존 원고·후보함·선택과 발행 이력은 유지합니다.

대시보드는 후보함과 실제 제출 요청을 구분하고 대표 확인 대기 결과 및 주제별 진행을 표시합니다. 자료 선택 → 명시적 조사 시작 → 주제별 결과 확인 → 구성·분석 확인 → 원고 반영 결정으로 이어집니다. 같은 후보함 버전은 기존 작업실을 열며, 변경된 선택은 새 요청입니다. 접수·작업 시작·대표 확인·승인 상태를 구분합니다. 자동으로 대표 승인을 대신하지 않습니다.

키워드 화면은 수집 자료의 주제 관찰과 실제 문서 수 시계열을 구분합니다. 검색량으로 표시하지 않으며, 동일 조건의 완결된 14일 자료가 없으면 증감을 보류합니다. 이미 수집된 데이터의 동기화만 사용합니다. 기존 유료 사용 한도와 스케줄을 늘리지 않습니다.

선택 기사 수만으로 완성도를 주장하지 않습니다. 분석 단계에서 시장 통계·키워드·국내외 사례·거래처 실행 항목·기존 발행물 차별점의 확보 및 부족 상태를 확인합니다. 실제 카카오 발송·결제·운영 리포트 게시에는 별도 최종 검토가 필요합니다.

검증: 프런트엔드 23개 테스트, 백엔드 52개 테스트, TypeScript 및 production build. 실제 스냅샷을 복사한 메모리 API로 2건 조사 요청·작업실 이동·재열기(중복 방지)를 확인했습니다. 실제 사용자 후보함은 이 테스트로 바꾸지 않았습니다.

## 알림·전체 검토 범위·키워드 연결 개선

선택 기사2건과 AI 주제3개는 총5개 검토 항목으로 집계하며, 원천자료 수·기사 묶음 요청 수와 구분합니다. 이전 기사 묶음은 중복 합산하지 않습니다. AI 제안도 조사 대상으로 유지합니다. 키워드에서 생성한 근거 연결 작업은 별도 검토 항목으로 더합니다.

알림함은 이 브라우저의 localStorage에 최대50개 작업 상태 기록을 보관합니다. 초기 상태는 알림함에만 표시하고 이후 상태 변경은 화면 배너로 알립니다. 선택적으로 사용자가 시스템 알림을 허용할 수 있습니다. 시스템 알림은 화면이 열려 있고 브라우저가 지원하는 동안에만 가능합니다. 닫힌 화면의 push나 카카오 알림은 구현하지 않았습니다. 20분 이상 queued 및1시간 이상 running에는 지연 안내를 표시합니다. 최근 정상 조회 시각·401 로그인 만료·연결 실패를 구분합니다. 자동 화면 조회20초와 AI 정기 처리15분은 다릅니다.

키워드의 연결된 기사 ID를 최신 스냅샷과 대조하고 실제 evidence 요청을 생성합니다. 접수 후 정확한 작업실로 연결하며 research→analysis→대표 adopt→draft의 기존 게이트를 재사용합니다. 같은 키워드의 열린 작업은 다시 열어 중복을 줄입니다. 근거 없는 직접 입력은 discover로 먼저 조사하며 요청·결과·후보 검토 경로를 보여줍니다.

검증: 프런트엔드26개 테스트 및 production build 통과. 메모리 API에서 하이볼 기사 접수→작업실 연결→결과 상태 변경→새 알림 배너를 확인했습니다. 실제 서비스의 대표 승인·후보함은 테스트로 변경하지 않았습니다.
