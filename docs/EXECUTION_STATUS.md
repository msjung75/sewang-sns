# 실행 상태와 지연 재점검

화면 서버 응답과 AI 작업 실행은 별개다. 현재 계획의 queued/running 작업과 독립 discover를 구분하고 queued는 실제 시작으로 표시하지 않는다. 마지막 상태 갱신부터 흐른 시간을 초 단위로 표시하며, 완료 예상 시간이나 가짜 진척률은 만들지 않는다. running도 20분 보고가 없으면 실행 확인이 필요하다. 시각을 확인할 수 없는 상태는 미확인이다.

Mac private editorial_watchdog는 최신 task/version, topic plan/revision·대표 결정, private 재시도 이력을 대조한다. 기존 5분 동기화에서 지연을 감지하고 기존 15분 AI 자동화가 재지시를 검토한다. 20분 지연, 재시도 사이 최소15분, 작업당2회 한도다. 실행 중인 주체가 불분명하면 복제하지 않고 사유를 보고한다. 이전 계획·대표 확인 대기·제외·보류·취소는 건드리지 않는다. 지연 알림은 기존 모바일 푸시 등록 기기에만 제공되고 미등록 상태에서 수신을 보장하지 않는다.

실제 재시작 CAS 성공 후에만 이력을 기록한다. 원문 조사와 별도 검토 결과물을 private 파일로 보관하고, 완료 전 최신 버전·원고 해시·출처/날짜/숫자/반대 설명을 교차 확인한다. 결과 등록은 대표 검토 대기이며 자동 승인·발행·유료 수집은 하지 않는다. 자동화 설정이 활성화돼도 개별 실행 성공을 의미하지 않는다. 현재 실행 오류는 별도 보고하며 완료라고 꾸미지 않는다.
